# @anthropic/node-util-lib

Industry-grade Node.js backend utility library built with TypeScript and Vite.

## Features

- Auth utilities (JWT, password hashing)
- Validation engine
- Structured logger
- Error handling (custom error classes, error handler)
- HTTP client wrapper
- Crypto utilities (hashing, encryption)
- Configuration loader
- Common helpers (string, array, object, date)
- Express middleware (error handler, request logger, CORS)
- TypeScript decorators (@Log, @Validate, @Cache)

## Quick Start

```bash
npm install
npm run build
npm test
npm run demo   # Run the demo Express server
```

## Build

Produces dual ESM/CJS output in `dist/`.
